# Password Generator

A simple password generator written in Python. It creates strong, random passwords using Python's `secrets` module, and lets you choose the length and which character types to include.

## Features

- Custom password length (minimum 4)
- Optional uppercase letters, numbers, and symbols
- Guarantees at least one character from each selected type
- Simple GUI built with `tkinter`
- Asks for confirmation before closing

## Requirements

- Python 3.6 or newer
- `tkinter` (included with most Python installs)

## Usage

Run the app:

```bash
python password_generator.py
```

Enter a length, tick the character types you want, and click **Generate**.
